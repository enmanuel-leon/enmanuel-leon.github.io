# Engineering Standards & Agent Instructions

See the full internal standards, content model, design rules, and verification workflow in:
[AGENTS.md](./AGENTS.md)

### Key Rules for Agents

1. **Content model parity:** update `data/cv.es.json` and `data/cv.en.json` together, including `meta.lastUpdated`. The validator checks deep key/array parity.
2. **Generated files:** `index.html`, `es/index.html`, `sitemap.xml`, `llms.txt`, and `site.webmanifest` are generated by `scripts/build-site.mjs`. Never edit them by hand.
3. **Markdown/PDF parity:** keep `export/Enmanuel_Leon_CV_ES.md` and `export/Enmanuel_Leon_Resume_EN.md` aligned with the JSON. Keep the `<!-- pdf:pagebreak -->` marker before the Interfell role.
4. **Mandatory rebuild:** after any content change, run:
   ```bash
   node scripts/build-site.mjs
   python3 scripts/build-pdf.py
   node scripts/validate.mjs
   ```
5. **Retired features:** do not reintroduce the terminal, particles, accent themes, projects placeholders, client-side JSON fetch, or the legacy custom modal.
6. **Private workspace:** never stage or commit files from `tmp/` (it is gitignored).

### Verification Commands

```bash
# Full gate: content parity, generated HTML, links, assets, Markdown/PDF parity, PDF budget
node scripts/validate.mjs

# Regenerate the static pages
node scripts/build-site.mjs

# Rebuild the ATS PDFs (strictly 2 pages)
node scripts/build-site.mjs:pdf

# JavaScript syntax
node --check assets/js/app.js

# HTML validity
npx --yes html-validate@11.21.1 index.html es/index.html 404.html

# Link hygiene + private-file check
git status
```
